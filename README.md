Fru
===

This is a snapshot of the fru/xrf ecosystem for a review of the "fru: Fast Random Forest Implementation" manuscript.

Sources
- xrf/ holds the engine library, cloned from https://gitlab.com/mbq/xrf
- fru-arrow/ holds both the pyfru Python package and fru-arrow Rust crate, cloned from https://github.com/kpiwonski/fru-arrow 
- fru/ holds the fru R package, cloned from https://gitlab.com/mbq/fru
